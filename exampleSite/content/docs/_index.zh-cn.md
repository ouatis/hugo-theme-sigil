# 文档

让 Sigil 成为你自己的主题所需的一切。

## 开始使用

Sigil 基于 Hugo 0.166 extended，无需构建步骤。
[README](https://github.com/ouatis/hugo-theme-sigil#installation) 说明了环境要求与安装方式；
[配置示例]({{% relref path="/config-example.md" lang="en" %}}) 提供了可直接复制的 `hugo.toml` 起点。

## 特色能力

理解 Sigil 最好的方式是阅读它。[排版]({{% relref "posts/typography/_index.md" %}}) 演示了旁注、公式、图表与代码；
[归档]({{% relref path="/archives.md" lang="en" %}}) 展示文章的索引方式。每项能力都通过 front matter 按需开启，
页面不声明就不会加载。

## API 参考

主题的公共契约自 v0.9.0 起冻结——列出的参数不会在没有弃用期的情况下改名或移除。
[API 契约]({{% relref path="/api.md" lang="en" %}}) 是权威参考；其中未列出的内容均属内部实现。
