# ドキュメント

Sigil を自分のものにするために必要なすべて。

## はじめに

Sigil は Hugo 0.166 extended で動作し、ビルド手順は不要です。
[README](https://github.com/ouatis/hugo-theme-sigil#installation) に要件とインストール方法、
[設定例]({{% relref path="/config-example.md" lang="en" %}}) にそのまま使える `hugo.toml` の出発点がまとめられています。

## 機能

Sigil を理解する最良の方法は、それを読むことです。[組版]({{% relref "posts/typography/_index.md" %}}) は傍注・数式・図・コードを、
[アーカイブ]({{% relref path="/archives.md" lang="en" %}}) は記事の索引のしかたを示します。各機能は front matter で任意に有効化でき、
ページが要求しないものは読み込まれません。

## API リファレンス

テーマの公開契約は v0.9.0 で凍結されています。記載されたパラメータは、非推奨期間を経ずに
改名・削除されることはありません。[API 契約]({{% relref path="/api.md" lang="en" %}}) が正式なリファレンスで、
そこに記載のないものは内部実装として扱ってください。
